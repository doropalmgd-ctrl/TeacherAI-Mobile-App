# TeacherAI - تطبيق ذكي لمساعدة المعلمين 📚

تطبيق موبايل متقدم يساعد المعلمين في إعداد الدروس والاختبارات والمحتوى التعليمي باستخدام الذكاء الاصطناعي.

## ✨ الميزات الرئيسية

- 🤖 **روبوت مساعد (KaroBot)** - سكرتير ذكي يساعد المعلم
- 📝 **إعداد الدروس** - إنشاء محتوى تعليمي احترافي
- ❓ **أسئلة الاختبارات** - توليد أسئلة متنوعة تلقائياً
- 🖼️ **الصور التعليمية** - إنشاء وتحرير الصور
- 🎥 **الفيديوهات** - دعم إنشاء وإدارة الفيديوهات التعليمية

## 🛠️ التقنيات المستخدمة

- **React Native** - تطبيق موبايل
- **Node.js + Express** - الخادم
- **MongoDB** - قاعدة البيانات
- **OpenAI API** - الذكاء الاصطناعي
